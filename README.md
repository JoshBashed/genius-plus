# Genius+

A browser extension adding essential editing features to Genius.

## Features

### 1. Clean SoundCloud links

Removes unnecessary query parameters from SoundCloud links, allowing easy
pasting into Genius.

### 2. Full quality artwork as PNG

Hover any cover on SoundCloud or Apple Music and a PNG button appears in its
corner.

Notes on quality:
* On Apple Music, the original artwork size is unknown. A 1024x1024 image is
  always returned, but it may be upscaled/downscaled from the original.
* SoundCloud uses the orignal artwork the creator uploaded.

## 3. Album Metadata Editor

In the React based album page on Genius, pressing "Manage Tracklist" opens a
dropdown with an option for the "Genius+ Metadata Editor". This opens a table of
all tracks on the album, with editable fields for each track's title, artist,
and other metadata.

## Architecture

```
src/
  manifest.ts              typed manifest, emitted at build time
  background/              service worker: CORS fallback image relay
  content/
    shared/                hover tracking, shadow-root overlay, labels
    soundcloud/            link cleaning (isolated + main world) + artwork
    appleMusic/            artwork
    genius/                bindings host for the album tools
  utilities/               result types, messaging, settings, URL rules
  popup/                   settings UI
```

A few decisions worth knowing:

- The manifest is written in TypeScript. `src/manifest.ts` exports a typed
  `chrome.runtime.ManifestV3`. A `manifest.json` is generated by a small rspack
  plugin from the TypeScript file.
- Overlays (for Apple Music & SoundCloud) are in a shadow root. This prevents
  style collisions with the host page.
- Never throwing errors is a design choice. Errors are `Result`s. Callers must
  handle errors! When calling that throws, it must be caught.

## Development

```sh
pnpm install
pnpm dev      # rspack watch build into dist/
pnpm build    # production build
pnpm check    # biome + tsc
```

Then load `dist/` at `chrome://extensions` with developer mode on.
